# 独立爱情树页面

- 地址：`/love/`，静态文件位于 `public/love/`，随 Firefly 构建发布。
- 该 HTML 不使用博客布局；不添加主站导航入口、返回链接、RSS 或站内搜索结果。
- `noindex, nofollow, noarchive` 用于请求搜索引擎不收录。公共 URL 和公开 GitHub 源码仍可读取内容，这不是访问控制。
- 文字在 `public/love/config.js`。称呼为用户指定的 `sy：`，没有原模板的两个人名、纪念日或计时器。
- 背景音乐沿用原项目，首次点击爱心后播放，右下角音乐按钮可暂停。
- 电脑保持左侧情书、右侧树的布局；手机（宽度不超过 700px）为上方情书、下方爱情树。

## 动画回退

接入、文案和移除计时器作为基础提交；随后将心跳、飘落增强作为独立提交。
只回退后一个动画提交即可保留 `/love/` 页面及这封信。

动画增强范围：2.4 秒一轮的轻微双心跳；点击后爱心平滑衔接树种子；飘落爱心上限由 4 增至 6；最后一批花瓣完整绽放。保留原来的生长、逐字书写和整体视觉。
系统开启“减少动态效果”时，直接呈现树与全文并停止持续飘落；切换到后台也会暂停飘落绘制。

手机布局修正作为后续独立提交：树生长完成后，用 1.6 秒平滑下移到信件下面，再开始逐字书写；预留全文高度，避免文字换行使树突然跳动。PC 分支和动画参数保持原样。

手机/桌面分支回归检查：`node --test tests/love-mobile.test.mjs`。

树下寄语由 `CONFIG.treeCaption` 配置。树完成生长与移动后，与情书同时逐字打出；颜色使用接近心形叶片的粉、橙、金色流光渐变。手机端在树下居中显示，系统开启“减少动态效果”时停用流光并直接显示全文。

点击开场后会启动全屏爱心花瓣：从右上向左下缓慢飘动，大小、起点、摆幅、颜色和旋转随机；电脑与手机端均最多同时显示 16 枚，不对手机端降低效果。页面进入后台或访客主动在系统中开启“减少动态效果”时自动停止并清空。树下寄语的流光周期为 24 秒。
