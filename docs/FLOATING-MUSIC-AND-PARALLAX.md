# 悬浮播放器与童话鼠标视差

## 参考来源

- https://blog.fqzlr.top/ 的实际开源仓库 https://github.com/fqzlr/shirone-fq ：MusicSidebarClient.svelte 与 musicSidebarStyles.ts。播放器几何、唱片/胶囊/完整控件形态及展开过渡按其源码适配；MIT 许可见 LICENSES/Shirone-fq.txt。源站手机端也渲染播放器，本站另外约束窄屏宽度和展开边界。
- https://www.jerrynis.com/ ：核对公开页面及实际发布的 Layout 脚本，观察到鼠标反方向最多约 14px/10px 的缓动位移。本站独立实现该行为，不引入或执行其整站脚本。

## 音乐

新增 FloatingMusicPlayer 仅为界面。订阅原 window.__fireflyMusic 的 fm:* 事件并调用其既有 API，不创建第二个 audio、不重复加载歌单，不改曲目顺序、播放记忆或音源回退。原管理器仅补充 loadedmetadata 时的进度广播，使暂停时已加载的时长与滑条也能及时显示。点击/悬停唱片展开，支持播放/暂停、前后曲、模式、音量、进度、列表、歌词与拖动。关闭仅隐藏控件；从现有音乐模块新增的唱片按钮重新打开。默认不自动播放。

根组件在 Layout 的 Swup 内容之外，导航时持续存在。拖动位置、关闭偏好使用独立 firefly:floating-music-* 键；不覆盖原音量和播放记忆。播放器全部样式限定在 music-float-* 命名空间，局部主题别名不写入 html/body。降低动态效果时取消旋转与展开动画。

## 鼠标视差

FairytaleParallax 组件、fairytale-parallax.ts 与独立样式构成单独功能。开关在童话设置「特效 → 鼠标视差」，默认开，独立存储 firefly:fairytale-parallax。仅 fullscreen + fairytale、电脑宽度 ≥1024px、鼠标精确指针、首页顶部时运行。滚动进入内容、切到其他页面、经典、手机、沉浸播放、降低动态效果或后台时归零并取消帧循环。图片轮播与滤镜位于另一层，不接管图片源、索引或播放状态；标题、导航和卡片不随鼠标移动。采用与刷新率无关的缓动，静止后停止调度。

## 文章暂停

童话文章路径 /posts/ 暂停正常轮播，同时失效已开始的下一图切换；离开文章时恢复先前的自动轮播意图。页面隐藏、沉浸播放、手动暂停与轮播总开关保持各自状态。经典等其他模式仍按原规则运行，32/21 张数量与图库不变。

## 独立回退

三个功能分为独立提交。视差无需改图库或原轮播即可撤回；播放器无需改音乐管理器即可撤回。回退文章暂停时只移除 MainGridLayout 中相应暂停分支与导航监听，不改原轮播逻辑。
