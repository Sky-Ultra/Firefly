# 沉浸式播放

入口位于右上角调色盘的“沉浸式播放”。这是临时的独立查看器，不修改壁纸模式、普通轮播开关或任何存储的显示偏好。

- 普通轮播：电脑 `carousel.count: 32`，手机 `carousel.mobileCount: 21`。所有直链入口仍生成一致的轮播位置。
- 沉浸查看器：进入时读取共享载体的完整设备图库，去重、洗牌，同一轮遍历全部图片。若当前普通轮播图片在该库中，以它开场。新增图片会随下一次正常构建自动加入完整图库，无需维护数量或清单。
- 使用现有高清 WebP；只加载当前与下一张，不批量下载完整图库。画面保留独立底部水波和默认开启的 Sky / 欢迎词，右上角有自动隐去的控制区；无导航或下滑箭头。
- 优先尝试浏览器原生全屏；不支持或拒绝时使用视口全屏对话框。对话框隔离页面交互和焦点，退出恢复调色盘按钮焦点与原滚动位置。
- Esc / Q / 退出按钮退出，左右方向键或触摸左右滑动切换，空格或播放按钮暂停。手机轻点显示退出等按钮，控制区提供 44px 触摸目标。
- 控制区的“显示中间文字”可单独关闭或开启 Sky 与欢迎词，使用独立浏览器偏好保存，不影响主页标题设置。欢迎词镜像现有打字内容，打开时监听、关闭时断开，不重置原打字机或创建额外打字计时器。
- 普通轮播暂停并保留其图片、当前位置和手动暂停状态，退出按进入前的状态恢复。后台停止沉浸计时，回到前台恢复；关闭、导航和组件移除都会取消未完成的加载和计时，避免异步旧回调重新启动。
- 加载失败跳过该图片，慢图等待最多 15 秒，保留上一幅画面。全部无法加载时显示退出重试提示。退出仍可随时使用。
- 减少动态效果偏好下关闭位移、缩放和水波动画，仅保留短淡入；不改变原有普通轮播设置。

实现：`ImmersiveSlideshow.astro` / `immersive-slideshow.ts` / `immersive-slideshow.css`。

生日示例提示仅配置在三篇指定文章中，匹配公开提示中的示例字符串。它不参与真正的密钥解析，也不免除错误计数或每日锁定。
