# 壁纸初始化与站内导航

2026-10-28 修复非主页直链、刷新后回退主题默认壁纸，以及返回主页时重新分配图片的问题。

- `MainGridLayout` 对所有入口生成相同的图库与电脑端 32 个、移动端 21 个轮播位置。图库继续自动扫描电脑和手机目录。
- 共用图库载体位于 Swup 替换区域之外，只初始化一次。文章列表和详情的载体引用共用数据，保留各自的缩略图/原图策略，不重复输出整份图库。
- 轮播等待随机分配完成再加载图片，避免先加载服务端回退图、随后突然切换。站内跳转不重新分配壁纸，也不重置已经加载的图片、当前位置或手动暂停状态。
- 手机非主页隐藏背景时暂停自动播放与预加载；返回主页后继续当前图片。文档后台、设备断点切换和最多保留三张解码图片的逻辑继续生效。
- 跨越 1024px 断点时重新同步当前模式的显隐和内容位置，避免手机直链进入后扩大窗口仍残留隐藏样式。
- 再次完整刷新会重新随机选择图片，但使用同一图库，不再只得到主题默认的六张图片。
- Swup 使用 `loadOnIdle: false`，不再等整页图片和外部组件加载完成后才初始化，减少首次进入后快速点击导航落入整页重载的情况。

回归验证覆盖共享图库、连续站内导航及返回主页、文章封面独立策略、等待初始化、隐藏背景恢复、手动暂停、后台切换与设备断点。
