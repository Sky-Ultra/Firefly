# 足迹页面

页面：`/places/`；入口：导航栏 → 我的 → 足迹。

## 添加真实足迹

编辑 `src/config/placesConfig.ts` 的 `places` 数组。每个地点包含：

- 唯一 `id`、名称、国家、地区、城市（可附英文）。
- `coordinates: [纬度, 经度]`，使用 WGS84，不直接使用高德 GCJ02 坐标。
- `visits: [{ start: "2026-10-03", end: "2026-10-05" }]`；同一地点再次到访时追加日期，不必重复创建地点。
- 只记得月份时使用 `{ start: "2026-05" }`；只记得旬时使用 `{ start: "2026-03", period: "mid" }`，`early` / `mid` / `late` 分别表示上旬、中旬、下旬。不要用月初、月末的具体日期冒充实际行程。排序内部参考值不作为真实到访日期保存或展示。
- `currentLocation: true` 可标注现居社区，`visits: []` 不虚构日期、不计旅行次数。现居点只参与“全部年份”，不会被算成某年的旅行。
- `mapZoom` 可设置点击定位的缩放级别；省级或岛屿级地点用 6，社区级定位用 13，不存储私人住址。
- `tags` 为旅行分类；`note` 是旅行记忆；可添加 `photos: [{ src: "/assets/images/places/xxx.jpg", alt: "照片说明" }]`。
- 照片保存于 `public/assets/images/places/`；无照片时显示占位插画。多张照片可逐张切换。网络配图通过 `credit` 保留作者、原作链接、许可及许可链接，页面标明非本人拍摄，不把配图中的景点当作已经确认的到访地点。
- 可选 `boundary` 为真实区域边界 `[纬度, 经度][]`；不填写时地图显示地点光晕，不冒充行政边界。

地区数按“国家/地区”去重；到访次数按日期区间计数；跨年到访参与各个覆盖年份的筛选。

当前有 16 个旅行地点、17 次到访，以及 1 个悉尼肯辛顿社区级现居点，共 17 个地图点位、12 个地区。成都合并为一个地点，保留 2025 年 5 月上旬、2026 年 4 月 10 日两条记录。年份为 2026、2025、2023。

未明确年份的三月行程按 2026 年记录；2025 年五月北京、成都按上旬，重庆按下旬。江西按用户补充信息标为九江；湖北暂保留省级记录；塔斯马尼亚暂保留岛屿级记录。后续只需追加或修正配置。

`previewWithExamples: false`、`examples: []`，不再展示示例地点、示例切换按钮或在页面下发示例数据。原示例 SVG 暂保留为未引用资源，未删除其他图片。

## 封面来源与许可

本批 17 张配图来自 Wikimedia Commons，使用其 960px JPEG 缩略图，合计约 2.5 MB，本地托管并懒加载；不依赖访客直接访问 Wikimedia 图片服务器。每张原作 URL、作者及许可保存在配置并在卡片下方署名。缩小与页面裁切已注明；原作品及相应调整后的图片继续遵循各自的 CC BY / CC BY-SA 许可，网站其他内容不因此改用这些许可。

肯辛顿封面为社区公开街景，不是私人住址。区域坐标是公开城市或行政区域的示意中心，不记录访客定位；湖北中心点仅作省级示意。

## 地图与隐私

地图使用本站托管的 Leaflet 1.9.4 与 OpenStreetMap 栅格底图，不需要账号或 API 密钥，不调用访客定位。
仅按当前地图视野请求底图，遵循浏览器缓存与地图署名要求，不提供离线下载或批量预取。
底图依赖访客与服务端的网络状况；加载失败会显示重试提示，地点列表不受影响。
未来更换服务时，在配置的 `map.tileUrl` 与 `map.attribution` 一起调整，保留新服务要求的署名。
