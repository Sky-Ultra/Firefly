# 新文章密文与密码位数

新发布的私密文章可在上传源码前使用 `sealContent(html, password)` 生成 `sealedContent`。它输出浏览器兼容的 AES-GCM 密文和从真实密码自动计算的字符数；每次封存使用新的随机上下文，避免重复使用密钥/IV 组合。原文、完整双语 HTML 和密码只保存在本地作者资料中，均不提交到公开仓库。

- 公开 Markdown 只包含标题、日期、介绍、密码提示、阅读统计、密文及通用锁定说明。`password: sealed` 是锁定标记，不是解锁密码。
- `sealedReadingStats` 保存实际正文统计；英文占位翻译也保存其实际统计。中文、英文正文及高光同时封存在同一份密文内。
- 文章分享和许可区作为不含私密正文的惰性模板保存，成功解密后再挂载，继续支持原来的海报与全文长图功能。
- 既有普通/`env:` 密码文章保持原有解密方式；占位文字通过构建时解析的真实密码自动生成。封存文章使用 `sealContent` 输出的长度，不能手动更改密码后只修改长度。
- 所有输入框统一显示“请输入密码：N位数”，语言切换时同步更新，不增加输入长度限制，不改变凌晨 04:00 重置或输错六次锁定的规则。

更新封存文章时，在本地修改双语正文，用相应密码重新封存，同时刷新两种语言的实际阅读统计。只提交新的密文与公开元数据。已有文章的公开历史不在此次变更中重写。
