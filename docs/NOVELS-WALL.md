# 小说推荐墙

路径 `/novels/`，入口“我的 → 小说”，关于我“喜欢的书”直接链接此处。首批去重后 60 部；《子夜》仅一次，用户遮住的一部不收录。小说集与用户另外点名的单篇保留为不同作品，《蚀》三部曲作为一条。

## 维护

- 数据：`src/config/novelsConfig.ts`。新增前先核对作者与书名，再检查标题及 `aliases`，不得用同名作品替代。`assertUniqueNovels` 在配置导入时检查标题、别名和 ID，重复会使构建失败。
- 不推测个人评分、读完状态或阅读日期。文体和区域标签可交叉，例如莎士比亚作品同时是外国文学和戏剧。
- 来源行、分类行、搜索取交集。每个选项的数量基于另一行和搜索词计算；无匹配的未选项禁用，已选条件保留，可直接重置。每页 12 部；排序与分页保持 DOM/键盘顺序一致。无脚本时显示完整书单。
- 数据不在浏览器自动抓取。后续新增来源应人工检查页面、作品、作者、开放范围和语言。维基文库直读页面通过公开 API 验证；古腾堡的英文版通过官方 CSV 元数据核对，不将英文原版冒充中文版。
- 微信读书和新华书店只标注试读，全文权限取决于平台；不能宣称永久免费全文。不提供未经验证的下载或破解入口。
- 60 张封面来自书籍平台公开目录，作书目识别用途，来源见下列研究记录；下载至 `public/assets/images/novels/` 并生成适合卡片的 WebP，页面不依赖图片站防盗链。原书与图片权利归各权利人，不托管正文。
- 布局参考 https://justpureh2o.cn/novels/ ，实现为本站自己的 Astro 页面与 DOM 控件，沿用主题色、淡色图案、果冻动效、夜间模式和减少动态效果偏好。

## 追加免费来源核验

追加青空文库《人间失格》日文原文、Faded Page《老人与海》英文原文，以及俄文维基文库的《童年》《我的大学》《变色龙》。全部标明语种；这些入口作为外文原版补充保留；最终中文覆盖见下节，后续可直接增补 sources。

- https://www.aozora.gr.jp/cards/000035/card301.html
- https://www.fadedpage.com/showbook.php?pid=20141070 （来源站说明公版范围为加拿大；不托管正文）
- 俄文维基文库官方 API 核对了三个作品条目及作者。
- UQAC 的两部加缪著作页面本次连接超时，暂不加入有效入口。
- 番茄搜索关键词页曾列出余华《活着》，但实际书籍页与章节页现在显示“抱歉，暂无内容”，暂不加入有效入口。
- 图书馆或会员平台的阶段性免费活动未作为永久开放直读。

## 中文免费平台最终核验

七猫公开实时搜索逐书匹配了书名、作者及可读章节。随后使用合集目录补齐单篇章节：鲁迅《阿Q正传》《孔乙己》《祝福》、茅盾《春蚕》和高尔基《我的大学》。中文免费入口优先于外文原版与平台试读。当前 51 部有中文免费阅读入口，9 部保留试读/部分篇目标注。

《蚀》入口只核验到《幻灭》，注明“部分篇目”，不计作完整的开放直读。《围城》等同名但作者不同的作品未使用。维基文库“春蠶”实际是刘基诗作，已剔除，改用茅盾合集中的小说章节。

实测七猫《鼠疫》第五部和《三体I》中段章节均可在网页显示正文与上一章/下一章，没有付费提示。平台正文仅用于阅读核验，不保存在本站。实时书目和章节链接记录：本机 `.site-refresh/novels/qimao-live-results.json`。


封面最终改用公开目录在阅读界面实际使用的较大尺寸（腾讯 t6 版本），59 张由最初的小缩略图升级，另 1 张使用七猫目录封面；全部实际宽度至少 250px，按卡片需要生成 WebP，没有放大低分辨率图片。

阅读状态与链接均按当前选中的来源更新：选择平台试读源时显示“平台试读”，切回全部后恢复优先中文免费来源。不会拿其他来源的开放状态替所选平台背书。部分篇目附可见版本说明。搜索、来源、分类共同取交集，数量会忽略本行选择但保留另一行条件计算。

页面初始化模块必须保留在 `MainGridLayout` 的插槽内；实测从全新主页首次站内跳转也会启用搜索、筛选与分页，避免布局之外的模块被 Swup 忽略。
