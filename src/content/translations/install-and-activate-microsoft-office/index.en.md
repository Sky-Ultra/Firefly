## 1 Introduction

Office Tool Plus is a powerful and practical Office deployment tool. It is open source, free, simple, and powerful.

Open-source project: [YerongAI/Office-Tool: Office Tool Plus localization projects.](https://github.com/YerongAI/Office-Tool)

Office Tool Plus is built on the Office Deployment Tool and makes deploying Office convenient. Its built-in Downloader engine can also help you download Office more quickly.

You can also use the other features and built-in utilities in Office Tool Plus to manage Office conveniently and efficiently!

### Currently supported products

- Microsoft 365
- Office 2016 - 2024
- Visio Online Plan 2 & Visio 2016 - 2024
- Project Online Desktop Client & Project 2016 - 2024
- Office 2019 and 2024 LTSC

## 2 Install Office Tool Plus

Visit [Office Tool Plus](https://www.officetool.plus/zh-cn/) to download it, or obtain a release directly from the GitHub project.

## 3 How do I install Office?

(Read this section if your computer does not have an official version of Office installed. Otherwise, skip it.)

![Office Tool Plus deployment page](../../posts/install-and-activate-microsoft-office/office-deployment-page.png)

Open the Deployment page.

Click the “Products” button below and choose the product you want to install. Microsoft 365 or Microsoft Office 2024 is recommended here.

![Office product and language selection](../../posts/install-and-activate-microsoft-office/office-products-and-languages.png)

On the page shown above, you can choose exactly which components to install. For example, if you do not need Access, you can omit that component to save storage space and deployment time.

Below that, you can choose the installation language. Usually, Chinese is all you need.

![Office deployment settings](../../posts/install-and-activate-microsoft-office/office-deployment-settings.png)

After completing the steps above, select the appropriate channel and choose Office Deployment Tool as the installation module. Carefully confirm every setting, click Start Deployment, and wait for the deployment to finish.

## 4 How do I activate Office?

![Office activation page](../../posts/install-and-activate-microsoft-office/office-activation-page.png)

Open the Activation tab and click Clear activation information.

![Clear activation information](../../posts/install-and-activate-microsoft-office/clear-activation-information.png)

Clear the settings from older versions of Office. If you do not clear them, the license information associated with the account may not be removable.

### Start activation

Steps:

1. Install an Office volume license. You need to select the volume license option here.
2. Set a KMS host address and save the setting.

[https://monitor.yerong.org/kms/](https://monitor.yerong.org/kms/)

If the address stops working, visit [https://monitor.yerong.org/kms/](https://monitor.yerong.org/kms/) for the latest KMS host address.

**If the activation steps above do not work, here is an alternative option.**

[Release HEU_KMS_Activator_v64.04.0 · zbezj/HEU_KMS_Activator](https://github.com/zbezj/HEU_KMS_Activator/releases/tag/64.0.0)

Visit that link to obtain the release.

> Disclaimer: Windows Defender may flag this tool. The project is open source at [Release HEU_KMS_Activator_v64.04.0 · zbezj/HEU_KMS_Activator](https://github.com/zbezj/HEU_KMS_Activator), follows an open-source license, and has more than 43,000 stars, so there is generally little need for concern about its security.

**Disable Windows Defender before use!!!**

After opening the software, select Office and activate it. If Windows is already activated, be sure to deselect Windows!!!
