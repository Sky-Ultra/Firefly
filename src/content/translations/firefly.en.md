## 🌟 Project overview

**Firefly** is a clean, modern personal blog theme built on Astro and the Fuwari template. It brings together a modular feature set and a highly customisable interface for technical writers and other creators.


**🖥️Live demo: [Firefly - Demo site](https://firefly.cuteleaf.cn/)**

## 🚀 Technical architecture

- **Static site generation**: Astro produces fast pages with strong SEO fundamentals.
- **TypeScript support**: Static typing catches mistakes earlier and makes the codebase easier to work in.
- **Responsive design**: Tailwind CSS adapts the layout across desktop and mobile screens.
- **Component-based development**: Astro and Svelte components keep features flexible and reusable.
