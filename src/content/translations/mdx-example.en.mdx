:::tip
The site accepts both `MDX` and `Markdown` posts. MDX can mix Markdown with components, though plain Markdown is usually enough unless a post needs more involved behaviour.
:::

## How Markdown and MDX differ
- Markdown (MD) is a lightweight markup language for writing formatted documents in plain text. Its small, readable syntax works especially well for documentation and blog posts.
- MDX extends Markdown with JSX. It can import and embed components, which makes interactive or data-driven sections possible inside an article.

| Feature | Markdown | MDX |
| :--- | :--- | :--- |
| Basic syntax | Supported (CommonMark) | Supported (CommonMark) |
| HTML tags | Supported | Supported (as JSX) |
| Component imports | Not supported | Supported (`import`) |
| Dynamic data | Not supported | Supported (JS expressions) |
| Styling | Limited (`class`/`style`) | Flexible (`className`/CSS-in-JS) |

## Writing JSX directly

HTML or JSX can also be written in place:
```
<div className="p-4 bg-blue-100 dark:bg-blue-900 rounded-lg my-4">
  这是一个自定义样式的 div 块，使用了 Tailwind CSS 类。
</div>
```
