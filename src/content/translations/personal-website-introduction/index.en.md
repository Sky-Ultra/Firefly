Welcome to my website. It is still in testing, so you may occasionally run into stability issues or slow-loading elements. If you have a suggestion, you can find the Firefly project on my GitHub profile and open a pull request. You can also reach me by email, WeChat, Instagram, or WhatsApp whenever those channels are available.

---

For a little more information about me, start with the **About Me** tab in the navigation bar.
![Where to find the About Me tab](../../posts/personal-website-introduction/about-me-tab.png)

---

This site began with the open-source Firefly project and has since been extensively customised. Mobile support in the original framework is not as strong as its desktop experience, although I have already made several rounds of substantial improvements. If you can, I would still recommend visiting from a computer as well. The mobile and desktop versions now use almost separate interface layouts and different image sets.

---

The main article area is below the homepage banner, where the post cards appear. On a computer, you will also see widgets around the articles. On a phone, scroll farther down to reach them.

---

Most of the site's features are available from the top navigation bar, shown below.  
**Home** returns to the page you are on now.  
The **Activity** section is not fully open while it is being tested—or, more honestly, while I finish building it. The pages under **My Space** are mostly complete, though text may still shift on devices with unusually narrow or wide aspect ratios. That is something I still need to improve. **About Me** currently introduces my tech stack; a personal timeline and experience section are planned for later.

![Desktop navigation and feature area](../../posts/personal-website-introduction/navbar-overview.png)

---

The site is built and deployed directly with Cloudflare Workers, using a domain registered through Tencent Cloud. My thanks to GitHub for hosting the source code and to Cloudflare for the project infrastructure.  
Special thanks to CMLiussss for wildcard-domain and DNS support, which helps the site remain accessible from mainland China. If the site is still unavailable there, try a connection routed through Hong Kong, Japan, Australia, or another region outside mainland China.  
The core customisation work was completed with GPT Codex and accounts for roughly 60% of all changes so far. The project has used around 500 million ChatGPT 5.6 sol tokens to date.
