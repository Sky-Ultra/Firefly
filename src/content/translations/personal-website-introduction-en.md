Welcome to my website! It is still in testing, so you may occasionally run into stability issues or slow-loading elements. If you have suggestions, you can find the Firefly project in my GitHub repository and open a pull request, or contact me by email, WeChat, Instagram, or WhatsApp when those channels are available.

For information about me, start with the **About Me** tab in the navigation bar.

---

This site began with the open-source Firefly project and has since been extensively customised. Mobile UI support is weaker than desktop support in the original framework, and I have already spent a fair amount of time improving it. If you can, please visit again from a computer. The mobile and desktop versions now use almost separate interface layouts and different image sets.

---

The main article area appears below the homepage header, where the post cards are listed. On a computer, you will also see widgets around the posts. On a phone, scroll farther down to find them.

---

Most of the site's features live in the top navigation bar, shown below. **Home** returns to the page you are on now. The **Activity** section is still being tested—in other words, I have not finished it yet. The pages under **Personal** are mostly complete, although text may still shift on devices with unusual aspect ratios. That is something I still need to improve. **About Me** currently introduces my tech stack; a personal timeline and experience section are planned for later.

The site is built and deployed directly with Cloudflare Workers, using a domain registered through Tencent Cloud. Thanks to GitHub for source hosting and Cloudflare for the project infrastructure.

Special thanks to CMLiussss for wildcard-domain and DNS support, which helps the site remain accessible from mainland China. If it is still unavailable there, try a connection routed through Hong Kong, Japan, Australia, or another region outside mainland China.

Most of the deeper customisation was completed with GPT Codex, accounting for roughly 80% of the site's code changes. The work has used around 500 million ChatGPT 5.6 sol tokens so far.
