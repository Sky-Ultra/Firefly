## 🔒 隐私政策

### 一、网站性质与适用范围

本站使用 Astro 构建，以静态页面提供主要内容，浏览文章不需要注册本站账号。静态网站并不意味着访问过程中完全不处理个人信息：评论后端、托管平台和第三方资源仍可能接收必要的数据。

本政策适用于本站页面及本站配置的互动功能。点击外部链接后，第三方网站对数据的处理由其自身政策说明。本站不会以出售访客个人信息为目的使用你提供的数据。

### 二、留言与文章评论

本站目前使用 **Twikoo**，在留言板及已开放评论的文章中提供留言、回复等功能，无需登录 GitHub。

- **你主动提交的信息**：昵称、邮箱、可选的网站地址，以及留言正文。昵称、头像、正文、时间和你填写的网站链接可能公开展示。请不要在公开留言中填写密码、住址、电话号码或他人的私人信息。
- **邮箱的用途**：用于评论身份标识和头像匹配；如果后端开启回复邮件，也可能用于向你发送相关回复通知，不用于本站的营销邮件。邮箱原文不会作为普通评论内容公开，但站点管理员可以在管理后台处理它。
- **技术信息**：评论服务可能接收并保存 IP 地址、浏览器及系统信息、页面路径和请求时间，用于反垃圾、限流、故障排查和评论管理。本站不在评论区公开展示 IP 地址或 IP 归属地；**不公开展示不等于后端不处理这些信息**。
- **头像服务**：填写数字 QQ 邮箱时，Twikoo 可以使用对应的 QQ 头像；其他邮箱可能使用 Gravatar 或默认头像。头像请求可能包含 QQ 号码或邮箱摘要，并向头像服务传递正常网络请求信息。邮箱摘要不是加密，也不保证无法被关联到原邮箱或头像账号。
- **服务与保存**：本站配置的 Twikoo 后端托管于 Netlify，留言不是仅保存在你的浏览器中。具体技术能力可参阅 [Twikoo 文档](https://twikoo.js.org/intro.html)。

如果不希望提交这些信息，可以只阅读、不使用留言功能。请不要冒用他人的邮箱或身份；无需公开真实姓名，也不要在留言正文中公开邮箱。

### 三、托管与第三方资源

为正常展示内容，本站会按页面和功能需要请求外部服务。相关请求可能在你打开页面时自动发出，并不一定等到你点击按钮后才发生。服务方通常能接收到 IP 地址、请求时间、资源地址、浏览器信息，以及浏览器实际发送的来源信息。

- **网站托管**：本站通过 GitHub Pages 发布静态页面。托管方可能处理访问日志，用于提供页面、保障安全和排查故障。参见 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。评论后端的托管行为由 [Netlify 隐私政策](https://www.netlify.com/privacy/)说明。
- **脚本与资源分发**：部分组件通过 jsDelivr 等 CDN 加载，评论脚本在主地址不可用时可能使用 npmmirror 等备用地址。
- **音乐**：播放器会通过 Meting 接口及备用接口获取歌单、封面、歌词和播放地址，并向 QQ 音乐、网易云音乐或返回的资源服务请求内容。这些服务可能接收资源请求及必要的网络信息。本站不提供音乐平台账号登录，也不读取你的音乐平台密码。
- **欢迎提示与天气**：通过 ipwho.is 查询 IP 对应的大致地区，并通过 Open-Meteo 获取该地区天气；天气请求会包含 IP 查询得到的近似经纬度。这里没有调用浏览器 GPS 定位，也不请求设备的精确位置权限，但外部服务仍会接触你的网络地址。
- **今日一言**：可能向一言（Hitokoto）接口请求短句。
- **足迹地图**：打开足迹页面时，地图会向 OpenStreetMap 请求当前视野的地图瓦片。地图展示的是站主记录的地点，不是自动记录访客的位置；相关请求遵循 [OpenStreetMap 基金会隐私政策](https://osmfoundation.org/wiki/Privacy_Policy)。
- **其他外部内容**：外部图片、视频、头像和嵌入内容由相应服务提供；访问 BiliBili、GitHub 等链接后，请同时查看其自身规则。

不同服务的处理地点和保存机制可能不同，数据可能在你所在地区以外处理。本站不能控制第三方的全部处理行为，也不能保证其服务始终可用。

### 四、访问统计

本站预留 **Umami** 访问统计支持，是否启用取决于部署配置，当前状态显示在本页顶部。未启用时，本站不会加载该统计脚本；侧栏的固定展示数字不等同于实时采集结果。评论组件的文章访问计数与 Umami 是不同功能。

启用 Umami 后，可能统计页面浏览量、访问来源、浏览器、系统、设备类别、大致地区及外链点击，用于了解访问情况和改进体验。根据 [Umami 官方说明](https://docs.umami.is/docs/faq)，其常规统计不使用追踪 Cookie；服务可能利用 IP 等请求信息生成匿名会话标识，但默认统计不保存原始 IP。匿名统计不意味着网络请求完全不涉及 IP，也不等于精确识别某一个人。本站不向统计事件主动附加评论邮箱或留言正文。

会话回放属于另一项功能，启用状态也在本页顶部单独列出。若未来调整为启用，应先更新本政策，说明采集范围和保护措施。

### 五、Cookie、浏览器存储与缓存

本站主要使用浏览器本地存储和缓存保存功能状态，而不是借此建立广告追踪档案。

- **偏好设置**：主题、语言、壁纸、特效和文章布局等选择可能保存在 Local Storage 中，便于下次访问沿用。
- **音乐播放记忆**：保存最近的歌曲标识、播放进度、音量及更新时间，用于恢复上次的位置。这是播放状态记忆，不是把整首音乐下载到本地；实际播放仍可能需要网络。
- **评论输入与草稿**：Twikoo 可能在浏览器中记住昵称、邮箱、网站和未发送的草稿，减少重复输入。在共用设备上使用后，建议清理相关站点数据。
- **临时状态与资源缓存**：会话存储可保存短期提示状态；浏览器缓存可保留图片、脚本等资源。天气和 IP 查询结果也会在本地短期缓存，减少重复请求。

这些本地状态不会因为“保存”这一动作就自动上传成本站的个人资料；但当你提交留言或请求第三方资源时，相应功能所需的数据仍会按前述方式传送。浏览器自身的同步功能由浏览器提供方管理。

你可以在浏览器设置中删除本站的 Cookie、Local Storage 和缓存，或限制脚本及外部资源。这样可能使设置恢复默认、播放记忆消失，或导致评论、地图等功能不可用。**清理本地数据不会删除已经提交到评论后端的留言**；无痕模式也不会隐藏你的网络 IP。
